## 2. Review findings

### Must fix before the wizard is usable
1. **`WizardNavigation` — `submit` prop is declared but never called.** On the last step the primary button calls `next()`, which the store clamps to a no-op. Call `submit` when `isLastStep`.
2. **No per-step validation / `canProceed`.** Spec §03 requires "at least one chip OR free-text" on steps 1–3 and a mandatory min/max on step 5. Nothing gates `next()` yet. Recommended: one zod schema per step in `utils/wizard/schema.ts`, keyed by `WizardStepId`, reused later by the API route.
3. **No session persistence.** Spec §03 ("State persistence … on accidental refresh"). Wrap the store in zustand `persist` with `createJSONStorage(() => sessionStorage)` and `partialize` to `{ currentStepIndex, draft }`; handle hydration so a refresh doesn't flash step 1.

### Should fix
4. **Back button is enabled on step 1** — `prev()` is a no-op there. Disable it (keeps layout stable) rather than hide it.
5. **No skip affordance for step 4.** `common.skip` exists in the dictionary and the step is optional by spec; add a ghost "رد کردن" shown only when `currentStepId === "antiPrefs"`.
6. **No loading state on submit.** The AI + scrape round-trip is 5–15 s. `Button` needs a `loading` prop and `WizardNavigation` an `isSubmitting` flag to prevent double-submit.
7. **`alreadyOwns` is `string[]`.** `OWNS_BY_INTEREST` is typed `readonly string[]`; make the owns ids `as const` (an `OWNS` array) so `alreadyOwns: Owns[]` is type-safe like every other group.
8. **`options.ts` has no `BUDGET_FLOOR`.** The dictionary already has `wizard.budget.errorFloor` with a `{floor}` placeholder; define the constant next to `BUDGET_PRESETS`.
9. **`types/` deletion.** Confirm whether `next dev`/`next build` regenerates this folder. If it does, add `types/` to `.gitignore` so it doesn't get re-committed in a stale state.

### Nits
10. `app/wizard/page.tsx` — `"use client"` is unnecessary; `WizardShell` already declares it. Leaving the page as a server component is preferable.
11. `WizardShell.tsx` — two empty `className=""` attributes.
12. `WizardNavigation.tsx` — `onClick={() => back()}` → `onClick={back}`; `flex flex-row` → `flex`.
13. `Chip.tsx` — the `compoundVariants` entry lists every variant, so it's equivalent to putting the classes directly on `selected: { true: … }`.
14. `store.ts` — `freeText?` is optional on every draft but `emptyDraft` always sets `""`. Making it required (`freeText: string`) removes `?? ""` guards in the step components.
15. Indentation: `utils/wizard/options.ts` is 2-space while the rest of `utils/` and `components/` are 4-space (CLAUDE.md says 2-space is for `i18n/` only).
16. `i18n/fa.ts` header comment and `CLAUDE.md` still reference `lib/wizard/options.ts`; the file lives at `utils/wizard/options.ts`.
