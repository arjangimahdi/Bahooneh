# 10 — Glossary

| Term | Definition |
|---|---|
| **Wizard** | The 5-step guided input flow that collects recipient, occasion, interests, anti-preferences, and budget |
| **Anti-Preferences** | User-specified exclusions: things the recipient dislikes, is allergic to, or already owns |
| **Query Intent** | A single structured, AI-generated search query object passed to the scraper layer |
| **Waiting Room** | The staged, animated loading experience shown during the 5–15s backend processing window |
| **AI Rationale** | The short explanatory text shown per product on the results page, explaining why the AI selected it |
| **Affiliate CTR** | Click-Through Rate on outbound affiliate links to partner e-commerce sites — the North Star metric |
| **Partner** | A third-party e-commerce site (e.g., Digikala, Snapshop) whose products Giftway recommends and links to via affiliate tracking |
| **Chips** | Predefined, clickable tag options on each wizard step; the zero-typing path through the wizard |
