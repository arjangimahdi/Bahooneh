# 07 — Scope & Roadmap Boundaries

## In Scope for MVP

- 5-step wizard (chips + free-text on every step)
- AI-driven structured query generation from wizard inputs
- Real-time scraping of partner e-commerce sites
- Dynamic, staged "AI thinking" loading experience
- Results page with real purchasable products, pricing, AI rationale, and affiliate links
- Core edge-case handling (see [06 — Results & Edge Cases](06-results-and-edge-cases.md))

## Explicitly Out of Scope for MVP

| Excluded Feature | Rationale |
|---|---|
| User accounts / profiles | MVP validates the core recommendation loop before investing in retention/identity infrastructure |
| Vision API (image-based search, e.g., "upload a photo of their room/style") | High complexity, unproven demand at MVP stage; revisit post-validation |
| Direct payment gateways | Business model is explicitly affiliate-referral, not transactional; payment stays with partner sites |

## Future Roadmap (Post-MVP)

Presented in suggested rough sequence, pending MVP learnings:

| Feature | Description | Strategic Rationale |
|---|---|---|
| **Smart Event Calendar** | Reminders for birthdays/anniversaries tied to saved recipients | Drives repeat usage without requiring the user to remember to come back — depends on user accounts |
| **Group Gifting** | Crowdfund/split the cost of a single gift among multiple contributors | Expands average order value and virality (multiple users invited per gifting occasion) |
| **AI-Generated Greeting Cards** | Pairs a recommended gift with a personalized card message | Low-cost engagement/monetization add-on, reinforces the "thoughtful" positioning |
| **Price Drop Alerts** | Notify users if a previously recommended product drops in price | Re-engagement lever; also plausible secondary affiliate revenue driver |
| **B2B Corporate Gifting** | Bulk recommendation flows for company gifting (employees, clients) | Opens a higher-AOV, higher-volume revenue channel distinct from consumer affiliate model |
